# Student-result-calculator
My first python project- Student Result Calculator.
About the Project

This is my first Python project. It calculates student total marks, average marks, grade, and pass/fail result.

Features

Takes student name as input

Takes marks for five subjects

Calculates total and average

Assigns a grade

Shows Pass or Fail

Identifies failed subjects

Python Concepts Used

Variables

Lists

For loops

If-elif-else conditions

Built-in functions

How to Run

Open the Python file in IDLE and select Run → Run Module.
